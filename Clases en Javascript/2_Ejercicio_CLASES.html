Ejercicio 1 · CLASES en JavaScript

Crea las clases Rectangulo y Caja usando la clase Punto

  • Rectangulo: se define con 2 puntos (esquinas opuestas). Métodos mostrar(), perimetro() y area().
  • Caja: es un rectángulo con profundidad. Métodos mostrar() y volumen().
  • La base y la altura del rectángulo se calculan a partir de sus dos puntos.

Resultados esperados: perímetro r1 = 16, área r1 = 16, área r2 = 405, volumen caja1 = 160, volumen caja2 = 6075.
